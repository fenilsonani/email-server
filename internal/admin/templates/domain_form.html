After Adding a Domain

After adding your domain, you'll need to configure DNS records. The DKIM DNS record will be displayed after the domain is created.

You can also use the CLI to manage DNS: 

# Show DKIM DNS record
mailserver dkim show yourdomain.com

# Check if DNS is configured correctly
mailserver dns check yourdomain.com
