Backup & Restore

Create a full backup of your mail server including database, emails, and DKIM keys.

Last Backup: {{.LastBackup}}
Upload a .tar.gz backup file
CLI Commands: 
# Create backup
mailserver backup /path/to/backup.tar.gz

# Restore from backup
mailserver restore /path/to/backup.tar.gz

# Export to remote server
mailserver export user@remote-server

DKIM Key Management

Automatically rotate DKIM keys that are older than the specified number of days.

days
Recommended: 90 days
CLI Commands: 
# Generate DKIM key for domain
mailserver dkim generate example.com

# Show DNS record
mailserver dkim show example.com

# Rotate specific domain
mailserver dkim rotate example.com

# Auto-rotate all old keys
mailserver dkim auto-rotate --days 90

# List all DKIM keys
mailserver dkim list
