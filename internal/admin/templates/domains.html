DKIM Key Management

You can also use the CLI to manage DKIM keys: 

# Generate DKIM key for a domain
mailserver dkim generate yourdomain.com

# Show DKIM DNS record
mailserver dkim show yourdomain.com

# Rotate DKIM key
mailserver dkim rotate yourdomain.com

# List all domains and DKIM status
mailserver dkim list
